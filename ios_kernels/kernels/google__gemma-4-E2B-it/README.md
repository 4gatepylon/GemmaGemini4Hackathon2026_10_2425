# google__gemma-4-E2B-it

Kernels for the text model of the HF model `google/gemma-4-E2B-it` (the smallest Gemma 4), one immutable `kernel_<name>_<YYYYMMDD-HHMM>/` folder per engine version.

Layout and naming: [../README.md](../README.md) and [../../CLAUDE.md](../../CLAUDE.md).
Lineage: `uv run utils/kernel_lineage.py` from `ios_kernels/`.
